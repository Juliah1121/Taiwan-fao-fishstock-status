# 臺灣漁獲資源狀態（FAO 1950–2024）

互動網頁：`index.html`（GitHub Pages 啟用後即為首頁）。

- 132 個 FAO 類群：FAO 三碼、ASFIS 學名與現行學名、綱、目、科、屬、本質脆弱度
- Sea Around Us Stock-status plots（SSP）逐年資源狀態
- CMSY++（CMSY++16.R，Froese et al.）估算 r、k、MSY、B/Bmsy、F/Fmsy 與 Kobe 分區

`figs/cmsy/` 為網頁使用的 CMSY++ 官方輸出圖。

資料：FAO FishStat 臺灣漁獲量；FAO ASFIS；物種生活史與脆弱度名錄；CMSY 先驗 r 資料庫。
注意：FAO 臺灣資料的分類拆分在 1989 年及近年有變動；鮪旗魚等跨洋區資源僅為臺灣漁獲份額。
